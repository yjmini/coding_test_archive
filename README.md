# Coding Test Archive

Baekjoon과 SWEA 문제 풀이를 Python/C++로 정리한 알고리즘 풀이 저장소입니다. 플랫폼, 난이도, 문제 번호 기준의 BaekjoonHub 스타일 디렉터리 구조를 유지합니다.

## 프로젝트 개요

코딩 테스트 대비 과정에서 해결한 문제들을 자동 생성된 문제별 폴더와 함께 관리합니다. 각 문제 폴더에는 풀이 코드와 문제 정보 README가 함께 들어 있어 풀이 이력을 빠르게 확인할 수 있습니다.

## 구성

| 플랫폼 | 주요 언어 | 내용 |
| --- | --- | --- |
| Baekjoon | Python, C++ | Bronze/Silver 중심 기초 알고리즘 풀이 |
| SWEA | Python, C++ | D1/D2 문제 및 구현 연습 |

## 기술 스택

- **Language**: Python, C++
- **Topics**: 구현, 문자열, 수학, 완전탐색, 기본 자료구조
- **Archive Format**: BaekjoonHub-style problem directories

## 프로젝트 구조

```text
.
├── 백준/
│   ├── Bronze/
│   └── Silver/
├── SWEA/
│   ├── D1/
│   └── D2/
└── README.md
```

## 활용 방식

- 문제별 폴더에서 `README.md`로 문제 정보 확인
- 같은 폴더의 `.py` 또는 `.cpp` 파일에서 제출 코드 확인
- 플랫폼/난이도별로 풀이 범위를 점검하며 복습

## 학습 포인트

- 입출력 처리와 기본 구현 속도 개선
- 문자열/배열/수학 문제 풀이 패턴 정리
- Python 풀이를 중심으로 하되 일부 문제는 C++로도 풀이
